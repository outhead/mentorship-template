# Mentorship Case Study / Шаблон менторской работы с дизайнером

Это обезличенный кейс реального менторинга мидл→синьор/лид дизайнера. Папка выложена как:

- (а) **учебный пример** — что обсуждается в менторинге дизайнера B2B-направления, какие договорённости рождаются, как трекать прогресс между встречами;
- (б) **шаблон для других менторов** — структура файлов, формат `commitments.md`, шаблон HTML-саммари, инструкции для Claude Code;
- (в) **демонстрация Claude Code / Cowork в роли ассистента ментора** — как нейросеть помогает превращать сырые транскрипции в структурированные саммари без потери смысла.

> Все имена, компании, конкретные продукты в материалах — заменены или удалены. Личные детали о семье, здоровье, финансах не публикуются. Совпадения с реальными людьми и организациями случайны.

## Контекст кейса

Дизайнер «Анна» — Middle в B2B-направлении банка. Сильный аналитический бэкграунд из техсферы, художественное образование, амбиция дорасти до Senior за полгода и далее до Lead. В работе — большой проект по CJM, попытки внедрить AI-инструменты в рутину, выступления на внутренних конференциях. Риски: высокая загруженность, синдром отличника, плотный график встреч.

## Workflow

### Подготовка к новой сессии
```bash
claude "Подготовься к сессии 3. Напомни что было на прошлой, какие договорённости висят, что стоит обсудить"
```

### После сессии
1. Транскрипция — в `sessions/session-NN/transcript.md`
2. Запуск:
```bash
claude "Сгенерируй саммари для сессии N. Транскрипция в sessions/session-NN/transcript.md"
```
3. Claude обновит `commitments.md`, создаст `sessions/session-NN/index.html` по шаблону, закроет выполненные договорённости, добавит новые.
4. Коммит:
```bash
git add . && git commit -m "Session N: [тема]" && git push
```

### Публикация (опционально)
GitHub Pages автоматически раскатывает `main` ветку. Ссылки:
- Главная: `https://[username].github.io/mentorship-template/`
- Конкретная сессия: `https://[username].github.io/mentorship-template/sessions/session-02/`
